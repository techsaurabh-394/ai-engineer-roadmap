## How to practise
1. Read the question. Answer **out loud** for 60 seconds. Then read the answer.
2. For every answer, prepare **one example from something you built** (this roadmap's code counts). Interviewers remember stories.
3. Do the system-design prompts with a friend or a timer: 10 to 15 minutes each.
4. Write your own questions in `08-interview-prep/my-questions.md` as you learn.

## Honest note
Answers are short on purpose. Where a topic moves fast (for example MCP transports), the answer tells you to check the current documentation.
